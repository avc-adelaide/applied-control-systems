# Copilot Instructions for Applied Control Systems Repository

## Repository Overview

This repository contains course materials for **Applied Control Systems** at Adelaide University. It's a LaTeX-based document system that generates comprehensive educational content including lecture notes, topic slides, practical exercises, and workshop materials.

### Key Purpose
- Supplement the textbook "Feedback Systems: An Introduction for Scientists and Engineers" by Åström and Murray
- Provide modular, structured course content for control systems engineering
- Enable automated generation and deployment of course materials to Canvas LMS

## Repository Structure

### Core Files
- `applied-control-systems.tex` - Main document that combines all course content
- `Makefile` - Build system for compiling LaTeX documents
- `beamer-control.cls` - Custom Beamer document class for presentations
- `beamer-control-*.sty` - Style files for different document types
- `control.bib` - Bibliography file for citations

### Content Organization
The course content is organized in a hierarchical structure:

```
acs-[MODULE]-[TOPIC]-[SUBTOPIC]-[NAME].tex
```

**Modules:**
- **Module 1**: Dynamical Systems (`acs-1-*`)
  - Topic 1.1: Introduction and System Modelling
  - Topic 1.2: Dynamic Behaviour  
  - Topic 1.3: Linear Systems
- **Module 2**: Control System Concepts (`acs-2-*`)
  - Topic 2.4: State Feedback and Observers
  - Topic 2.5: Frequency Domain Analysis
  - Topic 2.6: Stability Analysis
- **Module 3**: Control System Design (`acs-3-*`)
  - Topic 3.7: Controller Design
  - Topic 3.8: Performance and Robustness
  - Topic 3.9: Advanced Topics

**Practical Materials:**
- `acs-prac[1-6].tex` - Hands-on laboratory exercises
- `acs-workshop[1-9].tex` - Additional learning activities
- `acs-prac-project.tex` - Course project

### Supporting Directories
- `figures/` - Images and diagrams used in documents
- `topic[1-9]/` - Additional figures organized by topic
- `canvas/` - Canvas LMS configuration and assets
- `extra/` - Additional files for Canvas upload
- `pracs/` - Practical exercise materials
- `_build/` - Generated PDF outputs (auto-created)
- `_upload/` - Files prepared for Canvas upload (auto-created)

## Build System

### Make Targets
- `make help` - Display available commands
- `make topics` - Generate PDFs for individual topics
- `make pracs` - Generate practical exercise PDFs
- `make workshops` - Generate workshop PDFs  
- `make notes` - Generate combined lecture notes
- `make all` - Build all content types
- `make clean` - Remove build artifacts

### Upload Targets (requires Canvas credentials)
- `make upload[type]` - Build and upload specific content type
- `make uploadall` - Build and upload all content

### Build Process
1. LaTeX files are copied to `_build/` directory
2. XeLaTeX compilation with BibTeX for references
3. PDFs generated in `_build/`
4. Upload variants copy to `_upload/` and deploy to Canvas

## Canvas LMS Integration

### Configuration
- `canvas-config.lua` - Canvas API configuration
- `canvas-acs-upload-file.lua` - Upload script

### Authentication
- Uses `CANVAS_API_TOKEN` environment variable
- Automatic categorization based on filename patterns

## Development Workflow

### Local Development
1. Edit `.tex` files for content changes
2. Test compilation: `make all`
3. Review generated PDFs in `_build/`
4. Clean build artifacts: `make clean`

### Content Guidelines
- Use existing LaTeX macros and environments from style files
- Follow the modular structure for new content
- Include figures in appropriate `topic*/` directories
- Maintain consistent naming conventions

### Common File Types
- **Lecture content**: Use `beamer-control.cls` with topic-specific includes
- **Practical exercises**: Standalone documents with hands-on activities  
- **Workshop materials**: Interactive learning content
- **Figures**: PDF/SVG format preferred, organized by topic

## CI/CD Pipeline

### GitHub Actions
- **main.yaml**: Automated testing on all pushes/PRs
  - Installs TeX Live with required packages
  - Runs `make all` to validate compilation
  - Archives generated PDFs as artifacts

- **deploy.yaml**: Release and deployment workflow
  - Triggered on tagged releases or manual dispatch
  - Installs Lua and Canvas libraries
  - Builds and uploads all content to Canvas
  - Creates GitHub release with ZIP archive

### Dependencies
- XeLaTeX/TeX Live for document compilation
- Lua with Canvas LMS library for uploads
- Biber/BibTeX for bibliography processing

## Troubleshooting

### Common Issues
1. **LaTeX compilation errors**: Check for missing figures or malformed content
2. **Build failures**: Ensure all `.tex` files have proper syntax
3. **Upload issues**: Verify Canvas API token and network connectivity
4. **Missing figures**: Check that referenced images exist in correct directories

### Debugging Steps
1. Run `make clean` to clear build cache
2. Test individual components: `make topics`, `make pracs`, etc.
3. Check compilation logs in `_build/` directory
4. Validate LaTeX syntax in problematic files
